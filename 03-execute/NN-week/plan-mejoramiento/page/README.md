# Página pública de la Ludoteca

La portada explica las funciones, las reglas de préstamo y los roles de la ludoteca.

## Abrir la portada

Desde `plan-mejoramiento`, ejecuta:

```powershell
Start-Process .\page\index.html
```

## Revisar en escritorio y móvil

1. Comprueba que los enlaces Funciones, Préstamos y Roles llevan a su sección.
2. En Chrome, abre las herramientas con Ctrl + Shift + I y activa la vista de dispositivos con Ctrl + Shift + M. Ajusta el ancho a 375 px.
3. Abre Préstamos. Las reglas deben quedar encima de los pasos y el texto debe caber a lo ancho.
4. Pulsa Tab para recorrer el menú y Enter para abrir la sección seleccionada. El enlace enfocado debe mostrar un subrayado y un contorno visible.
